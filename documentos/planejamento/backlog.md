# Backlog de Desenvolvimento - Fase 2 (PataAmiga)

## Tarefas Técnicas

- [ ] **Configuração Inicial:** Setup do projeto Django e conexão à base de dados PostgreSQL.
- [ ] **Modelos de Dados (ORM):** Criar os Models `Abrigo`, `Animal` e `PedidoAdocao` com as respetivas chaves estrangeiras.
- [ ] **Gestão de Animais (CRUD):** Implementação das Views e Templates para registar, editar e listar animais.
- [ ] **Integração Externa:** Consumo da *The Dog/Cat API* para obtenção de raças, com tratamento de exceção para perfil SRD.
- [ ] **API REST:** Configuração do Django REST Framework (DRF) para expor os endpoints públicos de pesquisa de animais.
- [ ] **Formulários e Validação:** Implementação do formulário e fluxo de submissão de candidaturas à adoção.
